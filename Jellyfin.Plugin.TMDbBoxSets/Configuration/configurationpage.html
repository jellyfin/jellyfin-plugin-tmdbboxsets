TMDb Box Sets

Help

This plugin relies on the TMDb provider and TMDb's "belongs to collection" information. Please make sure it is enabled!


Specify minimum number of movies required to form a box set.

Enabled Libraries

Select movie libraries to include in box set creation. Movies from unchecked libraries will be excluded.

Exclude TMDb Collections

Selected collections will be excluded from box set creation.

Merge Boxsets

Define collections to merge into one box set. Execution will be enabled in a future update.
